| Section / module | Module | Teaching lessons | Measurable outcomes |
| --- | --- | --- | --- |
| 010 / 01 | Observability And Reliability | 3 | Choose metrics, logs or traces for a diagnostic question.; Explain instrumentation, collection and visualization responsibilities.; Distinguish an SLI, SLO and SLA.; Calculate an error budget and relate alerts to user impact. |
| 020 / 01 | Cloud Native Design | 2 | Explain loose coupling and microservice tradeoffs.; Relate resilience, elasticity and external state to replaceable workloads.; Distinguish serverless execution from the absence of servers.; Explain asynchronous delivery, retries and idempotency. |
| 020 / 02 | Cloud Native Ecosystem | 2 | Explain how open standards support interoperability.; Match representative projects to their technical roles.; Distinguish a specification, implementation and managed service.; Choose tools from requirements and operating constraints. |
| 030 / 01 | Community And Collaboration | 2 | Explain project governance and foundation maturity categories.; Distinguish licensing permission from contribution acceptance.; Describe an issue, pull request and review workflow.; Identify a suitable SIG or working group for a focused contribution. |

Every section begins with an introduction. Every module ends with a summary before the next module. YAML question banks follow the final module summary of each section; a domain review bank closes the course. They are indexed separately for future application integration.

This course has no labs or playgrounds, as requested by the maintainer. All material is readable without a cluster. Technical content remains draft until review; no runtime execution or lab validation is claimed.
