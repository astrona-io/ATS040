# Cloud Native Ecosystem

This module develops the reasoning needed to explain how open standards support interoperability.

## Learning Goals

- Explain how open standards support interoperability.
- Match representative projects to their technical roles.
- Distinguish a specification, implementation and managed service.
- Choose tools from requirements and operating constraints.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
