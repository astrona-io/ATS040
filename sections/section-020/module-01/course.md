# Cloud Native Design

This module develops the reasoning needed to explain loose coupling and microservice tradeoffs.

## Learning Goals

- Explain loose coupling and microservice tradeoffs.
- Relate resilience, elasticity and external state to replaceable workloads.
- Distinguish serverless execution from the absence of servers.
- Explain asynchronous delivery, retries and idempotency.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
