# Observability

This section teaches observability and reliability; OpenTelemetry, tracing and logs; Prometheus and PromQL; cloud cost management. These ideas help you explain system behavior and choose a suitable approach in a KCNA scenario, and you apply them on Prometheus on a kind cluster.

You will work through Observability And Reliability, OpenTelemetry Tracing And Logs, Prometheus And PromQL, Cloud Cost Management. Each module introduces its goals, teaches the concepts through examples, offers a playground for free practice and a graded lab, and closes with a summary. The section ends with an integration capstone and a knowledge check.

## Learning Outcomes

- Choose metrics, logs or traces for a diagnostic question.
- Explain instrumentation, collection and visualization responsibilities.
- Distinguish an SLI, SLO and SLA.
- Calculate an error budget and relate alerts to user impact.
- Scrape a workload with Prometheus, record its error ratio and alert on budget burn.
- Explain spans, traces and context propagation.
- Describe the OpenTelemetry API, SDK and Collector.
- Read basic PromQL selectors, rate and aggregation.
- Explain cost drivers, right-sizing and cost allocation.
