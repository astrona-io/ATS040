# Observability

This section teaches observability and reliability. These ideas help you explain system behavior and choose a suitable approach in a KCNA scenario.

You will work through Observability And Reliability. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. An original YAML question bank is prepared for the end of the section, with answer explanations for future quiz integration.

## Learning Outcomes

- Choose metrics, logs or traces for a diagnostic question.
- Explain instrumentation, collection and visualization responsibilities.
- Distinguish an SLI, SLO and SLA.
- Calculate an error budget and relate alerts to user impact.
