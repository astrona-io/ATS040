# Observability And Reliability

This module develops the reasoning needed to choose metrics, logs or traces for a diagnostic question.

## Learning Goals

- Choose metrics, logs or traces for a diagnostic question.
- Explain instrumentation, collection and visualization responsibilities.
- Distinguish an SLI, SLO and SLA.
- Calculate an error budget and relate alerts to user impact.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
