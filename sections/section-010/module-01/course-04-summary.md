# Summary

Metrics summarize numerical behavior, logs record events and traces connect timed operations. Useful observability requires appropriate instrumentation and a functioning collection, storage and query path. Signal design must account for sampling, sensitive data and cardinality.

Service-level indicators measure behavior, objectives set targets and agreements can define commitments and consequences. Error budgets follow from a precise indicator and window. Alerts should connect meaningful service impact or budget consumption to a clear response.
