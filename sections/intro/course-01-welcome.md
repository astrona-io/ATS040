# Welcome To The Course

This course is for learners preparing for the Kubernetes and Cloud Native Associate (KCNA) examination. It covers Cloud Native Architecture, worth 12% of the published curriculum. The examination tests knowledge through multiple-choice questions. The explanations build the reasoning needed to choose an answer and explain why the alternatives do not fit.

At the end, you can explain and compare the concepts in Observability, Cloud Native Ecosystem and Principles, Cloud Native Community and Collaboration. You also practice them on a local Kubernetes cluster. Technical terms and acronyms are defined when they appear. Examples use ordinary applications; names such as `scout` and `probe` identify workloads rather than changing the technical meaning.

Each section begins with an introduction and learning outcomes. Each module starts with a short map, continues with teaching lessons and ends with a summary. Each module has a playground, an environment for free practice with no grading, and a graded lab that you submit for checking. Each section ends with a capstone lab that combines its modules, and a knowledge check. A final quiz closes the course.

Read the examples carefully, identify which component does the work, and predict what changes when a condition changes. The knowledge checks are original practice questions and are not copied from the examination.
