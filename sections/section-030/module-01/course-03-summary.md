# Summary

Governance defines how a project makes and accepts decisions. Foundation maturity categories provide evidence of development and community practice without guaranteeing suitability. Licenses and contribution rules impose different obligations.

Useful collaboration begins with a focused, supported problem and proceeds through a reviewable change, appropriate checks and maintainer review. Special Interest Groups and working groups organize participation around documented scopes. Contributions can improve documentation and evidence as well as code.
