# Community And Collaboration

This module develops the reasoning needed to explain project governance and foundation maturity categories.

## Learning Goals

- Explain project governance and foundation maturity categories.
- Distinguish licensing permission from contribution acceptance.
- Describe an issue, pull request and review workflow.
- Identify a suitable SIG or working group for a focused contribution.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.

## Reading Order

1. Governance, Maturity And Licenses
2. Issues, Reviews And Working Groups
3. Summary
